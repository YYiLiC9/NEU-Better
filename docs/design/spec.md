# NEU Better 设计规范

版本：**M5 · 默认方向 A 静蓝**
适用范围：Windows / Android（同一套令牌与布局规则，差异只在布局密度）

## 1. 设计原则

- **清楚优先**：一屏只讲一件事，课表、登录、设置都避免信息过载。
- **克制**：深蓝只承担品牌与主要动作，大面积留给浅色画布与白色内容卡。
- **一致**：两端共用颜色、字号、圆角、间距与交互反馈。
- **本地感**：状态都可解释（「仅保存在本机」等），不制造云端依赖。

## 2. 颜色令牌（`lib/app/theme/app_theme.dart`，唯一取色处）

浅色：

| 令牌 | 值 | 用途 |
|---|---|---|
| `campusBlue` | `#0B4F9C` | 主色、品牌、主按钮、选中态 |
| `campusBlueDeep` | `#083B75` | 深色渐变端点、品牌面板 |
| `canvas` | `#F6F8FB` | 页面底色 |
| `surface` | `#FFFFFF` | 卡片、输入框 |
| `ink` | `#14243B` | 主文字、标题 |
| `muted` | `#5D7392` | 次要文字、说明 |
| `line` | `#D9E2EE` | 边线、分隔线 |
| `nowRed` | `#C2402A` | 考试卡、当前时刻线（仅此两处） |

深色（由 `AppColors.setDark(true)` 切换，简要）：`canvas #0D1520`、`surface #161F2C`、`campusBlue #5A97D6`，其余亮度相应调整。

品牌渐变：`#0B4F9C → #082E5C`。课程卡颜色由 `AppColors.pigmentFor(name)` 从 6 组传统色稳定取色（淡底 + 深字）。

## 3. 字体与层级

- 字体：Windows 使用系统 UI 字体栈（Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI）；Android 使用系统默认；Flutter 侧不额外打包字体。
- 页面标题 24–28sp / `w600–w700`；卡片标题 15–20sp / `w700`；正文 12–14sp / `w400`；标签 10–12sp / `w600`。
- 数字、学号、时间使用 `FontFeature.tabularFigures()`，避免跳动与错位。

## 4. 间距与圆角

- 基础间距单位 4px；常用 8 / 12 / 16 / 20 / 24。
- 卡片圆角 18–24；按钮 / 输入框圆角 11；小标签 8–10。
- 桌面侧栏 224；内容区按窗口宽度自适应；移动端水平内边距 16–20。
- 以 hairline 1px 分隔替代阴影。

## 5. 组件规范

### 登录页

- 桌面：左侧深蓝品牌面板（品牌 + 标语），右侧白色登录卡；一屏展示、宽屏不滚动。
- 移动：顶部深蓝 Hero（高度约屏高 20%），白色表单卡上移叠压 Hero，一屏展示、不滚动。
- 字段：学号、密码（可见性切换）、保持登录（默认开）、保存账号密码（默认开）。
- 不含「研究生 / 本科生」分类标签；错误用浅红底 + 深红文字，一句话说明下一步。

### 主界面

- 桌面：左侧固定导航（课表 / 寝室用电；通知、邮件为占位「后续」），底部电量状态条。
- 手机：底部导航（课表 / 寝室用电 / 设置），无顶部品牌栏；设置与退出在底部处理。
- 选中态用 `campusBlue`；状态点不使用高饱和绿色。

### 课表

- 周视图：7 天 × 12 节；左侧时间轴采用「开始 / 结束」两行；午休 / 晚休用横带留白；今日列 + 朱红当前时刻线。
- 课程卡用 `pigmentFor` 取色、圆角 8、hairline 边框、不用阴影；课程名居中并完整显示，地点 / 教师居左。
- 日视图：顶部星期 chip（顺序跟随「每周起始日」设置），议程卡与考试卡；日视图支持左右滑动切换星期并跨周。
- 考试卡使用 `nowRed` 系，考试名称居中、时间两行。

### 设置

- 桌面为居中弹窗；手机内嵌为主界面页面。
- 含：主题（浅色 / 深色 / 跟随系统）、每周起始日（周一 / 周日）；Windows 额外含托盘图标与关闭行为；手机含退出登录。

### 寝室用电

- 表单：完整房间码（与校区 / 楼栋 / 寝室号双向联动）、楼栋选择、提醒阈值、保存并查询；提醒阈值与「保存并查询」置底。
- 读数卡：剩余电量、房间信息、抄表时间；低于提醒线时提醒。

## 6. 交互与可访问性

- 可点击控件最小 44×44（移动）/ 32×32（桌面）。
- 表单错误就地显示；提交错误在表单顶部 banner。
- 动画 150–250ms、`easeOutCubic`（周切换 280ms，视图切换 160–200ms）。
- 对比度 ≥ 4.5:1；禁用态降低透明度而非修改文字颜色。
- Windows 默认窗口 1280×800，打开后居中显示。

## 7. 平台差异

| 维度 | Windows | Android |
|---|---|---|
| 登录布局 | 左品牌 + 右表单双栏 | Hero + 浮层单列 |
| 导航 | 左侧栏 | 底部导航 |
| 窗口 | 1280×800 居中，可缩放 | 锁定竖屏 |
| 字体 | Segoe UI 栈 | 系统默认 |
| 交互 | 鼠标 / 键盘 | 触摸 / 安全区 |
