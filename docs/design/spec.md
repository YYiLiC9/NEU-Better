# NEU Better 设计规范

版本：M1 · 默认方向 **A 静蓝**
适用范围：Windows / Android（后续 iOS 沿用同一套令牌与布局规则）

## 1. 设计原则

- **清楚优先**：一屏只讲一件事；课表、登录、设置都避免信息过载。
- **克制**：深蓝只承担品牌与主要动作，大面积留给浅色画布和白色内容卡。
- **一致**：Windows 与 Android 共用颜色、字号、圆角、间距和交互反馈；差异只在窗口/手机各自的布局密度。
- **本地感**：所有状态都可解释（“仅保存在本机”“已是当前学期”），不制造云端依赖。

## 2. 颜色令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `campusBlue` | `#0B4F9C` | 主色、品牌、主按钮、选中态 |
| `campusBlueDeep` | `#083B75` | 深色渐变端点、品牌面板 |
| `ink` | `#102A43` | 主文字、标题 |
| `muted` | `#627D98` | 次要文字、说明 |
| `faint` | `#829AB1` | 辅助信息、占位 |
| `canvas` | `#F4F8FD` | 页面底色 |
| `line` | `#DCE5F0` | 边线、分隔线 |
| `accent` | `#2CB1BC` | 在线/成功状态点缀 |
| `danger` | `#B42318` | 错误文字与错误边框 |

浅色渐变：`#F8FBFF → #E9F1FA`；深色品牌渐变：`#0B4F9C → #082E5C`。

## 3. 字体与层级

- 字体：Windows 使用系统 UI 字体（Segoe UI），Android 使用系统默认（Roboto / 厂商字体）；Flutter 侧不额外打包字体，保证下载即用。
- 页面标题：28–36sp / `w700` / 行高 1.2–1.45
- 卡片标题：15–24sp / `w700`
- 正文：12–14sp / `w400` / 行高 1.6–1.8
- 标签：10–12sp / `w600` / 字距 0.4–2.1
- 数字与学号：等宽感优先，避免表格错位。

## 4. 间距与圆角

- 基础间距单位：4px；常用 8 / 12 / 16 / 20 / 24 / 32。
- 卡片圆角：18–24；按钮/输入框圆角：11；小标签：8–10。
- 桌面内容最大宽度：980；登录表单最大宽度：430。
- 桌面侧栏宽：224；移动端页面水平内边距：18–20。

## 5. 组件规范

### 登录页

- 桌面：左侧深蓝品牌面板（品牌、标语、课表/一号通说明），右侧白色登录卡。
- 移动：顶部深蓝 Hero（品牌 + 标语），白色表单卡上浮 34px。
- 字段：学号、密码；密码可见性切换；保持登录默认开启。
- 错误：浅红底 + 深红文字，文案一句话说明下一步。
- 兜底入口：低调文字按钮“遇到验证码 / 二次验证？使用网页登录”。

### 主界面（M1 状态页）

- 桌面：左侧固定导航（课表/通知/邮件/寝室用电，后三项标记“后续”），右侧内容区。
- 移动：顶部品牌 + 退出，欢迎卡 + 下一步路线卡。
- 状态：在线点用 `accent`，不要用高饱和绿色。

### 课表（M2 预留）

- 以周为单位；顶部周次切换；左侧节次时间轴；课程块用校识蓝的不同透明度区分课程，不引入彩虹色。
- 单双周/自定义周在课程详情中显示，不在主表格堆叠标记。
- 桌面支持左右分栏（课表 + 详情），移动端使用底部详情面板。

## 6. 交互与可访问性

- 所有可点击控件最小触达 44×44（移动）/ 32×32（桌面）。
- 表单错误在字段下方就地显示；提交错误在表单顶部 banner 显示。
- 动画控制在 150–250ms，使用 `easeOutCubic`；避免连续弹跳。
- 文字与背景对比度至少 4.5:1；主按钮文字为白色，禁用态降低透明度而不是改文字色。
- 窗口最小尺寸（Windows）：960×640；目标默认 1280×800。

## 7. 平台差异

| 维度 | Windows | Android |
|---|---|---|
| 登录布局 | 左品牌 + 右表单双栏 | Hero + 浮层单列 |
| 导航 | 左侧栏 | 底部导航（M2 起） |
| 窗口 | 1280×800 默认，可缩放 | 竖屏优先，横屏自适应 |
| 字体 | Segoe UI | 系统默认 |
| 交互 | 鼠标 hover / 键盘 Tab | 触摸 / 安全区 |
